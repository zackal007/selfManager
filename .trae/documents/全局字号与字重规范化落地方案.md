# APP 字号与字重统一规范（Rule）

## 字号梯度（pt）
- NavBar 标题：`24`
- 页面主标题：`22`
- 区块标题：`18`
- 正文：`16`
- 次级文字/按钮：`14`
- 辅助说明/注释：`12`
- 最小可读：`≥11`（仅角标/徽章）
- 特殊展示（Hero/空状态大数值）：`28–34` 或更大，纳入白名单组件

## 字重体系（优先使用系统字体）
- 主标题：`Bold / Medium`
- 副标题：`Regular / Medium`
- 正文内容：`Regular`
- 辅助文字：`Light`
- 返回文字与导航操作：`Medium`

## 适配与一致性
- 动态字体：全面支持系统 Dynamic Type；字号随系统设置缩放，不低于最小可读阈值
- 设备适配：
  - iPhone：不缩至低于 `12pt` 正文与 `11pt` 角标
  - iPad：允许标题提升一个梯度（例如页面主标题 `22→24`）
- 平台一致性：iOS 为主、Android 参考同等梯度与字重映射，保持视觉层级一致
- 颜色/对比度：满足 WCAG 2.1 AA 对比度标准；浅色/深色模式均需达标

## 应用范围
- 覆盖所有界面组件：导航栏、按钮、卡片、列表、弹窗、标签、徽章等
- 文案类型与层级：标题、区块标题、正文、次级文字、辅助说明、状态/角标
- 特殊场景白名单：Hero 数字、空状态主提示、仪表盘关键数值（需评审后入库）

## 实施流程
- 设计令牌：以全局常量（如 `AppFont.*`）统一管理字号与字重
- 替换策略：分模块推进，逐步替换 `.font(.system(size:…))` 为设计令牌，不改动布局与颜色
- 适配验证：在 `Large/ExtraLarge` 动态字体下走查换行与截断；小尺寸机型验证最小字号

## 验收标准
- A/B 测试：在典型页面（首页、详情、列表、弹窗）验证可读性指标提升
- 无障碍：通过 WCAG 2.1 AA 级对比度与可读性要求
- 品牌一致：字号层级与字重风格与品牌调性一致（系统化统一）

## 交付物
- 字体样式规范文档（含示例与对比图）
- 设计系统组件库更新（统一使用设计令牌）
- 各场景应用效果对比报告（前后截图与测量数据）

## 长期维护
- 组件库固化：所有 UI 组件默认使用设计令牌
- 设计走查：每次上线前执行字号与字重检查
- 异常监控：Lint 检查直写 `.font(.system(size:))` 并告警；定期回归测试
