# 小组件测试报告

## 设备与系统
- iPhone 13 / iOS 17.x
- iPhone 15 Pro / iOS 18.x
- iPad Pro / iPadOS 17.x

## 功能验证
- 添加与配置：通过桌面添加三种尺寸，配置显示内容
- 数据展示：显示目标、联系人、记录摘要
- 刷新机制：主 App 前台与 CloudKit 同步后更新，时间线 30 分钟滚动

## 兼容性
- 浅色/深色模式对比度达标
- 动态字体与不同分辨率适配
- 低电量模式下仍正常显示与滚动刷新

## 问题与建议
- 建议在主 App 注册 URL Scheme，实现从小组件跳转到具体页面
- 如需更高频刷新，配合后台任务与通知策略
